1. Executive Summary & Problem Statement

Modern consumer enterprises publish thousands of copy assets each month across fragmented channels—social media advertisements, press statements, email campaigns, and landing pages. Under high-velocity deadlines, marketing workflows routinely trigger four critical hazards:

  • Regulatory Advertising Violations: Writers inadvertently make absolute or unprovable promises (e.g. "100% secure", "guaranteed returns", "#1 banking platform"), triggering immediate FTC, SEC, and financial advertising sanctions.
  • Brand Drift & Terminology Decay: Inconsistent product capitalization, spacing, and trademark degradation (e.g. "Nova Pay" instead of the registered trademark "NovaPay").
  • Accessibility & Visual Non-Compliance: Attached banner imagery shipping without descriptive screen-reader alternative text (alt), and low-contrast color palettes failing WCAG 2.1 AA readability thresholds (< 4.5:1).
  • Unvetted Factual Inaccuracies: Outdated or contradicted corporate claims contradicting authoritative enterprise truth sets.

BrandSentry delivers a standalone, self-sufficient governance engine built on a 3-step audit pipeline: deterministic rule execution, privacy-masked Google Gemini semantic evaluation, and an anti-hallucination validation gate—concluding in a traceable sign-off workflow.

5. Technical Architecture & Implementation Summary

BrandSentry is engineered as a modern, decoupled web application utilizing Next.js 16 (App Router) deployed as serverless functions on Vercel:

Step 1: Deterministic Rule Engine (Local & Immediate)
Scans submitted copy using case-preserving word-boundary regular expressions against registered brand terms. Evaluates absolute regulatory hazards (e.g., "100% secure", "guaranteed returns", "#1"). Evaluates WCAG relative luminance contrast ratios and image alt tags. All rule findings receive confidence 1.0 and authoritative source codes.
Step 2: AI Judge (Google Gemini 2.5 Flash with PII Redaction)
If not flagged confidential, submitted text undergoes PII sanitization ([EMAIL_REDACTED], [PHONE_REDACTED]). Text is passed to gemini-2.5-flash with full active guidelines and approved facts. Uses structured JSON schema output mode. Governed by a 20-second circuit breaker with automatic fallback to deterministic findings if the API times out.
Step 3: Anti-Hallucination Gate & Validator
Enforces a strict substring verification test: any model finding whose quoted span does not literally exist in the source document is permanently dropped. Verified findings are checked against corporate database codes. Overlapping spans are merged, prioritizing deterministic rule findings.
Persistence & Resilient Serverless State
Integrates with Supabase Postgres for relational storage. In serverless or disconnected environments without database credentials, BrandSentry automatically persists state to /tmp and localStorage, ensuring zero data loss, zero crashes, and flawless offline evaluation for judges.

Edge Case Hardening Under Normal & Adverse Use

  • Empty & Whitespace Inputs: Submitting empty or blank drafts is trapped client-side and server-side with polite user toasts; forms never submit blank records.
  • Double-Click & Re-Submission Prevention: Buttons (Accept Fix, Submit for Approval, Confirm Request) immediately disable while asynchronous requests are inflight to eliminate race conditions.
  • AI Failure Circuit Breaker: Tested against invalid keys, rate-limit 429s, and network drops: gracefully falls back to deterministic rule findings without throwing uncaught exceptions.
  • Backend Permission Gates: Direct PATCH calls to approve content by Creator or Reviewer roles return HTTP 403 Forbidden with descriptive error messages.
